# Semana 3 · API y Lambda
Dominio: D1 · 4 horas.

## Resultado
Distingues errores de validación de fallos internos y describes el flujo HTTP.

## Teoría (60 min)
Handler/eventos; API Gateway; JSON; timeout/memoria; invocación síncrona. Consulta proyecto/README.md; SAM en español. Toma cinco notas en tus propias palabras y un ejemplo por decisión.

## Laboratorio (90 min, incluida limpieza)
Compilar la base de proyecto. Ejecutar tests. Leer evento HTTP API v2; desplegar solo tras revisar costes. Explicar POST y GET.

Antes: presupuesto y perfil correctos. Después: eliminar recursos y registrar evidencia sin secretos.
Si no usas nube, marca explícitamente «simulado»; no lo registres como experiencia desplegada.
