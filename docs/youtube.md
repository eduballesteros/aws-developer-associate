## Cómo verlos
1. Abre solo el recurso de la semana. No veas seis cursos completos.
2. Pausa para escribir tres decisiones y aplica una en código.
3. Usa Java 21 y SDK Java v2 del proyecto como referencia; no copies runtimes antiguos.
4. Un vídeo viejo puede servir para conceptos; los precios, cuotas, SDK, consola y examen se contrastan con AWS.
5. No reproducir todas las demos: evalúa coste y limpieza antes de crear recursos.
6. Semanas 7 y 10 usan documentación para cubrir huecos sin inventar vídeos ni su cobertura.
7. Los vídeos no sustituyen las skills y servicios dentro de alcance de la [guía oficial](fuentes.md).

No se ha verificado un curso completo de YouTube en español que cubra todo DVA-C03.
